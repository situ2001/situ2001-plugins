# Linear Triage

Read the shared [workflow](../linear-recall/references/workflow.md).

1. Read the Requirement's Handoff and relevant descriptions, comments and supplied sources. Clarify the objective, scope and acceptance criteria; ask about unresolved judgments that change the intended outcome.
2. Reuse existing open work. Apply the shared ticket-scope rules when creating sub-issues; record established scope and acceptance criteria. A conversation may resolve a question without creating work.
3. Organize relevant relationships within the requested scope. Investigate unclear ownership; ask when the target remains ambiguous or a move would exceed the user's request.
4. Append useful increments not already recorded, distinguishing observations, proposals, confirmations and open questions. Link supporting material. Apply the shared default of leaving existing descriptions and Handoff unchanged unless their edit is explicitly requested.

Report affected Issues, clarified understanding and remaining decisions.
