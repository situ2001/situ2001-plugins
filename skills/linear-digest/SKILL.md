# Linear Digest

Read the shared [workflow](../linear-recall/references/workflow.md).

1. Read the complete current Handoff and relevant descriptions and comments for each selected Requirement. Include current conversation decisions and work evidence; inspect sources when their claims matter.
2. Reconcile confirmed increments using shared ownership, the focus and closure rules, and the context-retention rules below: task requirements into Issue descriptions; shared navigation and global constraints into Handoff. Keep unknown facts distinct from active work; a stopped question must not silently become a new task.
3. Apply routine consolidation under the user's Digest authorization. Ask before resolving judgments that change goal or scope. Issue completion does not adopt every discussion claim. Add comments only for useful context not already recorded.
4. Save using the shared write rules. Report meaningful changes, links and remaining decisions. If the baselines already reflect the confirmed context, report no changes; no new Issue or summary comment is needed merely to mark Digest.

## Preserve continuation context

- Preserve background, constraints and decision rationale that a fresh agent needs to understand the goal and make sound decisions, even beyond the immediate next step. Absence from recent discussion does not make a topic obsolete.
- Merge, rewrite or omit inherited baseline content according to its relevance to continuation. Retain relevant rejected alternatives and deferred questions with what would settle them; an unresolved question alone does not require retention. Completed logs and temporary investigation details need not enter the baseline when they no longer affect decisions. Existing comments remain history; omitted baseline material needs no separate archive solely for preservation.
- Before replacing background with a path or URL, verify that the artifact contains it and identify the reading location. Save needed context found only in conversation or temporary handoffs into its owning Linear record; preserve relevant primary-source links. Follow known sources to fill material gaps and state what could not be checked.
- Separate agreed requirements, historical proposals, observed implementation and assumptions; record material conflicts. Distinguish enduring background from operational snapshots that need rechecking. Keep task progress and evidence with the owning Issue rather than gathering everything into Handoff.
- Compare the reconciled records with the previous baseline and relevant increments: can a fresh agent recover the needed background, decisions and constraints through these records and their verified references?
